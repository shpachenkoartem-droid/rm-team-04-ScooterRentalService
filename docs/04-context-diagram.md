# 4. Контекстная диаграмма

Система — «чёрный ящик». Номера на стрелках соответствуют строкам таблицы потоков. Пунктиром показана возможная внешняя система проверки возраста (Q-04), её использование ещё не согласовано.

![Контекстная диаграмма](assets/context-diagram.svg)

## Таблица потоков данных

| № | Источник | Получатель | Данные |
|---|---|---|---|
| 1 | Арендатор | Система | Регистрационные данные, данные для входа и проверки возраста, QR-код самоката, запрос привязки карты (платёжные данные через платёжный сервис), запрос старта и завершения поездки, обращение в поддержку. |
| 2 | Система | Арендатор | Карта свободных самокатов, парковок и геозон, тариф, сумма предавторизации, заряд, статус и стоимость поездки, уведомление о въезде в зону ограничения скорости, уведомление о запрете парковки, результат оплаты. |
| 3 | Администрация города | Система | Актуальные геозоны, разрешённые парковки и ограничения скорости (EI-06). |
| 4 | Сотрудник сервисной службы | Система | Принятие задачи, статус самоката, отчёт о зарядке или ремонте. |
| 5 | Система | Сотрудник сервисной службы | Задачи на зарядку / ремонт: номер самоката, координаты, приблизительный адрес, тип работы, заряд и диагностические данные. |
| 6 | Система | Оператор поддержки | Обращения, данные арендатора и его поездки, координаты и статус замка, история списаний и последние четыре цифры карты. |
| 7 | Оператор поддержки | Система | Запрос принудительного завершения поездки, запрос корректировки / возврата, задача сервисной службе, результат обработки обращения. |
| 8 | Система | Контроллер самоката | Команды открытия / закрытия замка и данные геозон с лимитами скорости (EI-01). |
| 9 | Контроллер самоката | Система | GPS-координаты, заряд в процентах, статус замка, коды неисправностей, подтверждение исполнения команды и остановки (EI-02, EI-03). |
| 10 | Система | Картографический сервис | Запрос карты и адреса по координатам (EI-05). |
| 11 | Картографический сервис | Система | Картографические данные, адрес по координатам (EI-05). |
| 12 | Система | Платёжный сервис | Запрос привязки карты, предавторизации, списания, отмены блокировки и возврата (EI-04). |
| 13 | Платёжный сервис | Система | Статусы платёжных операций, идентификаторы транзакций (EI-04). |
| 14 | Система | Возможная система проверки возраста | Запрос проверки возраста (вопрос Q-04). |
| 15 | Возможная система проверки возраста | Система | Результат проверки возраста (вопрос Q-04). |
