# 2. Требования по Вигерсу

Требования версии 1.1 — проект изменений по замечаниям. Метки «Допущение» и ссылки на вопросы обозначают несогласованные параметры. ID сохранены; перенесённые требования отмечены отдельно.

## Бизнес-требования (BR)

| ID | Требование |
|---|---|
| BR-01 | К концу сезона (6 месяцев) обеспечить в среднем 4 поездки в день на самокат и ни одного штрафа за парковку за счёт запуска сервиса аренды парка из 1500 самокатов с геозонами запрета парковки и ограничения скорости, обеспечивающими соблюдение требований администрации города. |

## Пользовательские требования (UR)

| ID | Требование |
|---|---|
| UR-01 | Арендатор хочет пройти одноразовую верификацию возраста при регистрации, чтобы не проходить её каждый раз. |
| UR-02 | Арендатор хочет видеть ближайшие разрешённые парковки, чтобы завершить поездку. |
| UR-03 | Арендатор хочет получать уведомление при въезде в зону ограничения скорости, чтобы знать о действующем ограничении. |
| UR-04 | Арендатор хочет начинать поездку по QR-коду и видеть стоимость аренды, чтобы пользоваться сервисом без ручного ввода номера самоката и планировать расходы. |
| UR-05 | Сотрудник сервисной службы хочет получать задачи на зарядку и ремонт с местоположением самоката, чтобы обслуживать парк. |
| UR-06 | Оператор поддержки хочет завершать поездку при техническом сбое с соблюдением правил парковки и корректировать ошибочные списания, чтобы помочь арендатору. |
| UR-07 | Арендатор хочет видеть свободные самокаты и их заряд на карте, чтобы выбрать самокат для поездки. |

UR-04–UR-07 уточнены на основе уже существующих [историй](08-user-stories.md), [Job Stories](09-job-stories.md) и границ MVP. Связи — в [матрице трассировки](traceability.md).

## Функциональные требования (FR)

| ID | Требование |
|---|---|
| FR-01 | При запросе завершения поездки система проверяет актуальные GPS-координаты контроллера. Если самокат вне разрешённой парковки, система не завершает поездку, продолжает тарификацию, показывает сообщение «Здесь парковка запрещена» и ближайшие разрешённые парковки на карте. |
| FR-02 | Система рассчитывает и отображает стоимость активной поездки по тарифу: 50 рублей за старт и 7 рублей за минуту. Правило расчёта неполной минуты определяется по [Q-07](06-questions.md). |
| FR-03 | После подтверждения завершения поездки система запрашивает списание фактической стоимости с привязанной карты в счёт предавторизации и снятие неиспользованного остатка блокировки. Если стоимость превышает блокировку либо платёж не проходит, завершённая поездка не возобновляется; порядок доплаты и взыскания задолженности — [Q-14](06-questions.md). |
| FR-04 | При сканировании QR-кода свободного и доступного для аренды самоката система проверяет регистрацию, возраст, отсутствие другой активной поездки, наличие карты и успешную предавторизацию; затем отправляет команду открытия замка. Поездка начинается после подтверждения открытия замка. |
| FR-05 | При получении кода неисправности от контроллера система создаёт задачу на ремонт, а при получении заряда ниже 25% — задачу на зарядку. Задача содержит номер самоката, координаты и тип работы. Порог 25% — [допущение A-05](07-assumptions-risks.md). |
| FR-06 | При регистрации система проверяет, что арендатору исполнилось 18 лет, способом, согласуемым по [Q-04](06-questions.md). После успешной проверки повторная верификация при обычном входе не требуется. До подтверждения возраста аренда недоступна. |
| FR-07 | При въезде самоката в зону ограничения скорости система отправляет арендатору уведомление о действующем ограничении. |
| FR-08 | Система отображает свободные самокаты на карте в радиусе 15 км от местоположения арендатора. Радиус — [допущение A-02](07-assumptions-risks.md), уточняется по Q-08. Если геолокация телефона недоступна, система сообщает об этом. |
| FR-09 | Система отображает разрешённые парковки и зоны ограничения скорости на карте по актуальным данным администрации города. |
| FR-10 | При запросе завершения поездки на разрешённой парковке и подтверждении остановки самоката система запрашивает закрытие замка. После подтверждения блокировки фиксирует момент окончания поездки и прекращает тарификацию. При ненадёжных координатах завершение не подтверждается до проверки. |
| FR-11 | Система позволяет оператору поддержки инициировать завершение чужой активной поездки только с выполнением условий FR-01 и FR-10. При невозможности подтвердить парковку или блокировку система регистрирует обращение и задачу сервисной службе, не помечая поездку завершённой. |
| FR-12 | Система позволяет сотруднику сервисной службы взять задачу, отметить выполнение и изменить статус самоката «на обслуживании» / «доступен». Самокат становится доступным после завершения необходимого обслуживания и проверки готовности. |
| FR-13 | Перед началом поездки система отображает тариф, сумму предавторизации и текущий уровень заряда самоката. Размер предавторизации — [Q-13](06-questions.md). |
| FR-14 | Система позволяет оператору поддержки инициировать корректировку списания по обращению арендатора. Сумма, основание и результат операции фиксируются. Правила расчёта корректировки — [Q-12](06-questions.md); возврат выполняется только по согласованному правилу. |
| FR-15 | Система позволяет арендатору зарегистрироваться, войти в личный кабинет и привязать платёжную карту посредством платёжного сервиса. |
| FR-16 | Система отображает сотруднику сервисной службы задачи на зарядку и ремонт и приблизительные адреса по координатам самокатов. Список задач на зарядку содержит до 20 записей на страницу и сортируется по расстоянию от согласованной точки отсчёта (Q-10). |
| FR-17 | До открытия замка система запрашивает предавторизацию на привязанной карте. При отказе платежа аренда не начинается; при подтверждённом неуспешном старте блокировка отменяется. Размер блокировки — Q-13. |

FR-08 заменяет NFR-01 без изменения значения радиуса. FR-06–FR-17 отражают замечания и уточнения уже описанных возможностей; новые связи зафиксированы в матрице.

## Нефункциональные требования (NFR)

| ID | Требование |
|---|---|
| NFR-02 | Итоговая стоимость поездки отображается арендатору не позднее 5 секунд после подтверждения завершения поездки. [Допущение A-03](07-assumptions-risks.md). |
| NFR-03 | Функции старта и завершения поездки доступны не менее 99,5% времени за сезон. Доступность измеряется как доля времени, когда обе функции доступны, от общего времени сезона. [Допущение A-04](07-assumptions-risks.md); порядок учёта внешних сбоев — Q-09. |
| NFR-04 | При успешных проверках, доступности контроллера и успешной предавторизации замок открывается не позднее 5 секунд после сканирования QR-кода. [Допущение A-03](07-assumptions-risks.md). |

NFR-01 перенесено в FR-08; ID NFR-01 повторно не используется.

## Ограничения (CON)

| ID | Требование |
|---|---|
| CON-02 | Местоположение самоката определяется только по GPS контроллера, установленного на самокате; геолокация телефона используется для отображения карты. |

CON-01 перенесено в [BP-05](01-business-context.md#16-бизнес-правила) как допущение, ID CON-01 повторно не используется.

## Внешние интерфейсы (EI)

| ID | Направление | Требование |
|---|---|---|
| EI-01 | Система → контроллер | Передача команд «Открыть замок», «Закрыть замок» и данных геозон с лимитами скорости. Контроллер применяет ограничения скорости; блокировка замка допустима только при подтверждённой остановке. Конкретный протокол согласуется с поставщиком (Q-15). |
| EI-02 | Контроллер → система | Передача GPS-координат каждые 10 секунд (интервал из версии 1.0, подтверждение — Q-15). |
| EI-03 | Контроллер → система | Передача уровня заряда в процентах, статуса замка и кодов неисправностей вместе с координатами; подтверждение выполнения команды и остановки перед закрытием замка. Возможности контроллера и точность данных — Q-15. |
| EI-04 | Система ↔ платёжный сервис | Привязка карты, запрос предавторизации, списания, отмены блокировки и возврата средств; получение статусов операций и идентификаторов транзакций. |
| EI-05 | Система ↔ картографический сервис | Запрос карты и адреса по координатам; получение картографических данных и адреса. |
| EI-06 | Администрация города → система | Получение актуальных геозон, разрешённых парковок и ограничений скорости. Формат и периодичность — Q-01–Q-03, Q-05. |

Система проверки возраста не определена до ответа на Q-04. См. [контекстную диаграмму](04-context-diagram.md).
