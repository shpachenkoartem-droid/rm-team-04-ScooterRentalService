Пользовательские требования:
1) пользователь хочеи прейти одноразовую верификацию возраста при регистрации, чтобы не проходитб ее каждый раз
2) пользователь хочет видеть ближайшие места парковок, чтобы завершить поездку
3) пользователь хочет получать уведомление о приближении к парковой зоне, чтобы знать об ограничении скорости

Функциональные требования:
1) Если пользователь хочет совершить поездку в запретной зоне, то система отправляет уведомление пользователю, что он не может это сделать 
2) Систкма рассчитывает стоимость по тарифу в реальном времени
3) При завершении поездки система автоматически выставояет счёт 
4) При сканировании пользователем qr-кода система открывает замок на соответсвующем самокате
5) При выходе из строя самоката сервисная служба видит его координаты на карте
