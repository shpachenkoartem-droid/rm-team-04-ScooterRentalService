## Пользовательские требования (UR)


| ID | Требование |
|---|---|
| UR-01 | Пользователь хочет пройти одноразовую верификацию возраста при регистрации, чтобы не проходить её каждый раз. |
| UR-02 | Пользователь хочет видеть ближайшие места парковок, чтобы завершить поездку. |
| UR-03 | Пользователь хочет получать уведомление о приближении к парковой зоне, чтобы знать об ограничении скорости. |


## Функциональные требования (FR)


| ID | Требование |
|---|---|
| FR-01 | Если пользователь хочет завершить поездку в запретной зоне, то система отправляет уведомление пользователю о том, что он не может этого сделать. |
| FR-02 | Система рассчитывает стоимость по тарифу в реальном времени. |
| FR-03 | При завершении поездки система автоматически выставляет счёт. |
| FR-04 | При сканировании пользователем QR-кода система открывает замок на соответствующем самокате. |
| FR-05 | При выходе из строя самоката сервисная служба видит его координаты на карте. |


## Нефункциональные требования (NFR)


| ID | Требование |
|---|---|
| NFR-01 | Пользователь видит самокаты в радиусе 15 км от себя. |
| NFR-02 | Система рассчитывает стоимость по тарифу не более минуты. |


## Ограничения (CON)


| ID | Требование |
|---|---|
| CON-01 | Время поездки не может превышать 3 часа. |
| CON-02 | Постоянное подключение к геолокации контроллером самоката должно использоваться. |


## Внешние интерфейсы (EI)


| ID | Требование |
|---|---|
| EI-01 | Система должна передавать на контроллер самоката команду «Открыть замок». |
| EI-02 | Контроллер самоката должен передавать GPS-координаты системе каждые 10 секунд. |
