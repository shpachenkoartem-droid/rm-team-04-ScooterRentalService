Пользовательские требования:
1) пользователь хочет прейти одноразовую верификацию возраста при регистрации, чтобы не проходит ее каждый раз
2) пользователь хочет видеть ближайшие места парковок, чтобы завершить поездку
3) пользователь хочет получать уведомление о приближении к парковой зоне, чтобы знать об ограничении скорости

Функциональные требования:
1) Если пользователь хочет совершить поездку в запретной зоне, то система отправляет уведомление пользователю, что он не может это сделать 
2) Система рассчитывает стоимость по тарифу в реальном времени
3) При завершении поездки система автоматически выставляет счёт 
4) При сканировании пользователем qr-кода система открывает замок на соответствующем самокате
5) При выходе из строя самоката сервисная служба видит его координаты на карте 

Нефункциональные требования:
1) Пользователь видит самокаты в радиусе 15 км от себя
2) Система рассчитывает стоимость по тарифу не более минуты

Ограничения:
1) Время поездки не может превышать 3 часа
2) Контроль за самокатом должно использоваться
