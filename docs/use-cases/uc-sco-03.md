# UC-SCO-03. Принудительное завершение поездки


| Поле | Значение |
|---|---|
| Основное лицо | Оператор поддержки |
| Другие действующие лица | Арендатор (вторичное лицо); контроллер самоката, платёжный сервис (вспомогательные лица) |
| Предусловия | 1. У арендатора есть активная поездка.<br>2. Арендатор обратился в службу поддержки. |


## Основной сценарий

Через команду контроллеру самоката «Принудительное завершение».

1. Оператор поддержки принимает обращение арендатора.
2. Оператор отправляет команду контроллеру самоката для завершения поездки.
3. Замок самоката заблокировался.
4. Поездка в системе завершилась.

## Альтернативные сценарии

Не указаны в исходной работе.


## Исключения


### Исключительный сценарий А — контроллер самоката не получает команду завершения поездки.

Отклонение от шага 3.
- 3а. Замок самоката не блокируется.
- 3а.1. Оператор замораживает поездку.
- 3а.2. Оператор вызывает сервисную службу.
- 3а.3. Поездка в системе принимает статус «В обработке».

Не указаны в исходной работе.
