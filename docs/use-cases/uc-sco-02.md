# UC-SCO-02. Начало поездки по QR-коду


| Поле | Значение |
|---|---|
| Основное лицо | Арендатор (инициатор аренды) |
| Другие действующие лица | Контроллер самоката, платёжный сервис |
| Предусловия | Арендатор зарегистрирован, ему 18 лет или больше. |


## Основной сценарий

Через QR-код.

1. Арендатор открывает приложение.
2. Арендатор сканирует QR-код на самокате.
3. Платёжный сервис списывает стартовую сумму с привязанной карты пользователя.
4. Контроллер самоката разблокирует замок самоката.
5. Арендатор получает уведомление «Самокат готов к поездке».

## Альтернативные сценарии

Не указаны в исходной работе.


## Исключения


### Исключительный сценарий А — карта не привязана.

Отклонение от шага 3.
- 3а. Система обнаруживает, что карта не привязана.
- 3а.1. Система отправляет арендатору уведомление «Не найдено привязанной карты».
- 3а.2. Система предлагает форму привязки карты.
- 3а.3. Арендатор привязывает карту.
- 3а.4. Возврат к шагу 3 основного сценария.
- 3а.5. Если арендатор отказывается, сценарий завершается без аренды.

### Исключительный сценарий Б — заряд самоката низкий.

Отклонение от шага 3.
- 3б. Система видит, что заряд самоката низкий.
- 3б.1. Система отправляет арендатору уведомление «Заряд самоката низкий».
- 3б.2. Система предлагает арендатору три ближайших самоката для аренды.
- 3б.3. Если арендатор согласен, осуществляется возврат к шагу 2 основного сценария.
- 3б.4. Если арендатор отказывается, сценарий завершается без аренды.

## Постусловия

При успехе:
- Самокат арендован и помечен занятым в системе.
- Платёжная транзакция старта завершена.
При неуспехе:
- Самокат не арендован и доступен в системе.
- Арендатор получает причину отказа и может попробовать снова.
