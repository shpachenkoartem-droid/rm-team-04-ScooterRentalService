# 5. Глоссарий


| Термин | Определение |
|---|---|
| Поездка | Период использования самоката арендатором: от сканирования кода до оплаты поездки. |
| Геозона | Область на карте с заданными правилами использования самоката. |
| Предавторизация (заморозка суммы) | Временная блокировка суммы на счету арендатора перед началом поездки для проверки платёжеспособности. После сумма списывается в счёт оплаты. |
| Тариф | Набор правил расчёта стоимости поездки: цена старта поездки, цена минуты. |
