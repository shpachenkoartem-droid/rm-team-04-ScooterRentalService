# 6. Вопросы

a) Кто со стороны города отвечает за передачу и согласование геозон?
б) Какие виды геозон задаёт город (запрет поездки, зоны с ограничением скорости)
в) Как часто город меняет геозоны?
г) Как будет подтверждаться возраст пользователем: самостоятельно или
через скан паспорта, или подтверждение Госуслуг?
д) В каком виде город передаёт геозоны (файл, API, внешний портал)?
e) Какой бюджет у проекта?

Пояснения (цели) вопросов:
а) Нужно понимать, к кому обращаться для определения геозоны.
б) Какие конкретно ограничения накладывает геозона.
в) Когда (как часто) обновлять геозоны.
г) Для соблюдения законодательства.
д) Для понимания структуры проекта.
е) Для понимания рамок проекта.
